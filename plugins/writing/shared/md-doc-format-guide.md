## 1. 문서 메타 정보

- 문서 상단의 구성 순서: **문서 제목 → 메타 정보 표 → 머리말 → 목차 → 본문**
- 메타 정보 표의 열: `항목`, `내용`
  - 항목 열: 가운데 정렬, 굵게 표시
  - 내용 열: 왼쪽 정렬
- 메타 정보 표의 항목: 문서의 특성에 맞는 필요한 항목만 작성(예: 작성 상태, 연관 문서, 범위, 실행 환경)
- 머리말과 출처는 메타 정보 표에서 제외
  - 머리말: 2장의 형식
  - 출처: 11장의 각주 형식
- 메타 정보 표와 본문 표의 구분
  - 메타 정보 표에는 캡션, 표 번호, 가운데 정렬용 HTML 래퍼 생략
  - 본문 표의 번호 매기기에서 메타 정보 표 제외

```markdown
# 문서 제목

| 항목 | 내용 |
| :---: | :--- |
| **작성 상태** | 초안 |
| **연관 문서** | [`README.md`](./README.md) |
```

## 2. 머리말

- 위치: 메타 정보 표 아래, `#### 목차` 위
- 형식: 인용문(`>`), 예시는 3장
- 내용: 문서의 목적과 다루는 내용의 짧은 요약

## 3. 목차

- 위치: 머리말 바로 아래
- 제목: `#### 목차`
- 본문 제목이 없으면 목차 생략
- 목차 항목: 본문 제목으로 가는 링크 목록
  - 링크 텍스트: 번호를 포함하여 제목과 똑같이 작성
  - 앵커: GitHub 방식
- 포함 범위: 장(H2), 절(H3), 소절(H4) 전체
- 들여쓰기: 한 단계 내려갈 때마다 두 칸
- 각주는 목차에서 제외
- 본문 제목을 추가, 삭제, 수정하면 목차도 함께 수정

```markdown
> 머리말로서 문서의 목적과 다루는 내용을 짧게 요약하여 작성.

#### 목차

- [1. 장 제목](#1-장-제목)
  - [1.1. 절 제목](#11-절-제목)
    - [1.1.1. 소절 제목](#111-소절-제목)
- [2. 장 제목](#2-장-제목)
```

## 4. 제목

- 제목 문법: ATX 제목 문법(`# 제목`)
- H1(`#`): 문서 제목 전용
  - 문서당 한 번만 작성
  - 문서 제목에는 번호 생략
- 장, 절, 소절: H2(`##`), H3(`###`), H4(`####`)
- 목차 제목: H4(`####`)
- 장, 절, 소절 제목의 번호: `1.`, `1.1.`, `1.1.1.`처럼 번호 뒤에 마침표 표기

```markdown
# 문서 제목

## 1. 장 제목

### 1.1. 절 제목

#### 1.1.1. 소절 제목

{본문 내용}
```

## 5. 빈 줄

- 제목, 문단, 목록, 코드 블록, 표, 독립 수식 블록, HTML 블록, 캡션 사이에 빈 줄 하나

## 6. 목록

- 순서가 없는 목록: `-`
- 순서가 중요한 절차: `1.`, `2.` 같은 번호 목록
- 하위 목록의 들여쓰기
  - 기본: 한 단계 내려갈 때마다 두 칸
  - 번호 목록의 하위 목록: 번호 뒤 글자 위치에 맞춘 세 칸

## 7. 강조와 코드

- 강조: `**굵게**`
- 파일 경로, 명령, 설정 키, 코드 식별자: 인라인 코드(``` `...` ```)
- 다른 문서의 참조: ``[`문서 파일 이름`](문서 상대 경로)`` 형식의 링크
  - 다른 폴더의 문서도 링크 텍스트에는 파일 이름만, 링크 주소에는 폴더 경로까지 작성
  - 예: ``[`02-agent-loop.md`](./02-agent-loop.md)``, ``[`01-coding-agent.md`](../02-coding-agent/01-coding-agent.md)``
- 같은 문서 안의 장과 절의 참조: `N절`, `N.N절`
- 코드 블록: 여는 펜스에 언어 명시
  - 디렉터리 트리나 일반 텍스트: `text`

## 8. 수식

- 문법: LaTeX
- 본문 안의 수식: `$...$`
- 독립 수식: 여는 `$$`와 닫는 `$$`를 각각 별도 줄에 배치
- 수식 유도의 근거, 가정, 치환 관계: `\because`
- 결론 수식: `\therefore`
- 여러 단계의 유도: `aligned`
  - 등호 등의 위치 정렬: `&`
  - 줄 구분: `\\`
- 행렬: `bmatrix`
- 벡터: `\mathbf`

## 9. 이미지

- 문서에 이미지를 삽입하거나 수정할 때는 아래 형식을 그대로 사용

```markdown
<div align="center">

  <img src="./figures/fNN-{name}.svg" width=80%>

  *Figure N. {caption}*
</div>

```

## 10. 표

- 문서에 표를 삽입하거나 수정할 때는 아래 형식을 그대로 사용
- `<div>` 안의 표 위아래 빈 줄은 표 렌더링에 필요하므로 유지

```markdown
<div align="center">

| 열 제목 1 | 열 제목 2 |
| :---: | :--- |
| 내용 1 | 내용 2 |

*Table N. {caption}*
</div>

```

## 11. 각주

- 각주의 용도
  - 외부 문서에서 가져온 정의, 설명, 주장의 출처 표기(GitHub 각주 문법)
  - 본문 흐름에서 벗어나는 보충 설명의 분리
- 본문의 각주 참조: 인용한 문장의 마침표 앞에 `[^N]`
- 각주 정의(`[^N]: 내용`)의 위치: 문서 마지막, 번호 순서대로 한 줄에 하나씩
  - GitHub가 각주를 문서 끝에 모아 렌더링하므로 `## 참고 문서` 같은 제목은 생략
- 각주 내용의 형식
  - 외부 문서 출처: `[문서 이름: 가져온 내용](링크)`
    - 같은 문서에 언어별 판이 있으면 문서 이름 뒤에 `(국문)`, `(영문)` 표기
  - 보충 설명: 링크 없이 내용만 작성
- 출처 링크: 가져온 문장을 하이라이트하는 텍스트 프래그먼트(`#:~:text=시작 문구,끝 문구`) 링크
  - 시작 문구와 끝 문구: 단어 단위로 분리, 한국어는 조사가 붙은 어절 전체
  - 시작 문구: 문서 안에서 한 번만 나오는 문구
  - 퍼센트 인코딩 대상: 공백(`%20`), 쉼표(`%2C`), 하이픈(`%2D`), 괄호(`%28`, `%29`)
  - 한글: 인코딩 없이 그대로 표기
  - 리다이렉트되는 주소: 최종 주소
- 각주 이름: 숫자만 사용, 본문에서 처음 참조한 순서대로 1부터 부여
- 같은 문서의 인용
  - 하이라이트 범위가 다르면 별도 번호
  - 같은 범위를 다시 인용하면 같은 번호

```markdown
LLM 하나는 텍스트로만 응답한다[^1]. 본문 흐름을 끊는 설명은 각주로 뺀다[^2].

[^1]: [문서 이름 (국문): 가져온 내용](https://example.com/page#:~:text=start%20phrase,end%20phrase)
[^2]: 링크 없이 덧붙이는 보충 설명이다.
```
