# 작업 자료

- 작업 전에 `${CLAUDE_SKILL_DIR}/references/korean-writing-guide.md`의 원문 전체가 context에 있는지 확인한다.
- 원문이 없거나 요약만 있으면 파일을 다시 읽는다. 원문이 있으면 다시 읽지 않는다.

# 절차

1. 작업 자료의 「1. 기본 원칙」에 따라 글의 종류에 맞는 문체, 용어 표기, 문장 부호를 정한다.
2. 작업 자료의 「2. 문장 작성 원칙과 예시」를 지키며 문장을 쓴다.
3. 다 쓴 뒤 작업 자료의 원칙에 비추어 문장을 다시 확인하고 고친다.
