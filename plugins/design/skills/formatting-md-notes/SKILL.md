# 작업 자료

아래 파일의 원문이 context에 없으면 먼저 읽는다. 요약만 있으면 없는 것으로 본다.

- `${CLAUDE_SKILL_DIR}/references/md-format-guide.md`

# 절차

1. 문서를 쓰기 전에 작업 자료의 형식을 확인한다.
2. 작업 자료의 형식에 맞춰 문서를 쓴다.
3. 다 쓴 뒤 목차, 표 번호, 그림 번호, 각주 번호가 본문과 맞는지 확인한다.
