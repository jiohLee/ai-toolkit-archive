# 마크다운 노트 스타일 가이드

- 아래 범위에는 적용하지 않는다.
  - AI에게 제공하는 지침 파일: `CLAUDE.md`, `.claude/` 아래 파일(rules, skills 등)
  - AI가 대화에서 하는 답변

## 1. 노트 메타 정보

- 노트 상단은 **노트 제목 → 메타 정보 표 → 개요 → 목차 → 본문** 순서로 구성한다.
- 메타 정보는 `항목`, `내용`의 두 열로 작성한다.
- 항목 열은 가운데 정렬하고 굵게 표시한다.
- 내용 열은 왼쪽 정렬한다.
- 필요한 항목만 작성한다. 노트의 특성에 따라 작성 상태, 연관 문서, 범위, 실행 환경 등을 넣는다.
- 개요와 참고 문서는 메타 정보 표에 넣지 않는다. 개요는 2장, 참고 문서는 11장을 따른다.
- 메타 정보 표는 본문 표와 구분하여 캡션, 표 번호, 가운데 정렬용 HTML 래퍼를 붙이지 않는다. 본문 표의 번호에도 포함하지 않는다.

```markdown
# 노트 제목

| 항목 | 내용 |
| :---: | :--- |
| **작성 상태** | 초안 |
| **연관 문서** | [`README.md`](./README.md) |
```

## 2. 개요

- 개요는 메타 정보 표 아래, `#### 목차` 위에 인용문(`>`)으로 쓴다. 예시는 3장에 있다.
- 개요에는 노트의 목적과 다루는 내용을 1~2문장으로 쓴다.
- 개요에는 `Figure N.`, `Table N.` 같은 캡션 번호를 붙이지 않는다.

## 3. 목차

- 목차는 개요 바로 아래에 `#### 목차` 제목으로 작성한다.
- 본문 제목이 없으면 목차를 생략한다.
- 목차 항목은 본문 제목으로 가는 링크 목록으로 작성한다. 링크 텍스트는 번호를 포함해 제목과 똑같이 쓰고, 앵커는 GitHub 방식을 따른다.
- 장(H2), 절(H3), 소절(H4)을 모두 포함하고, 한 단계 내려갈 때마다 두 칸씩 들여쓴다.
- 참고 문서 장이 있으면 목차 마지막 항목으로 넣는다.
- 본문 제목을 추가, 삭제, 수정하면 목차도 함께 고친다.

```markdown
> 노트의 목적과 다루는 내용

#### 목차

- [1. 장 제목](#1-장-제목)
  - [1.1. 절 제목](#11-절-제목)
    - [1.1.1. 소절 제목](#111-소절-제목)
- [2. 장 제목](#2-장-제목)
- [참고 문서](#참고-문서)
```

## 4. 제목

- ATX 제목 문법(`# 제목`)을 사용한다.
- H1(`#`)은 노트 제목에만 사용하며, 노트당 한 번만 작성한다. 노트 제목에는 번호를 붙이지 않는다.
- 장, 절, 소절에는 H2(`##`), H3(`###`), H4(`####`)를 사용한다.
- 목차 제목은 H4(`####`)로 작성한다.
- 장, 절, 소절 제목에는 `1.`, `1.1.`, `1.1.1.`처럼 번호 뒤에 마침표를 찍어 번호를 붙인다.
- 참고 문서 장(`## 참고 문서`)에는 번호를 붙이지 않는다.

```markdown
# 노트 제목

## 1. 장 제목

### 1.1. 절 제목

#### 1.1.1. 소절 제목

{본문 내용}
```

## 5. 빈 줄

- 제목, 문단, 목록, 코드 블록, 표, 독립 수식 블록, HTML 블록, 캡션 사이에는 빈 줄을 하나 둔다.

## 6. 목록

- 순서가 없는 목록은 `-`를 사용한다.
- 순서가 중요한 절차는 `1.`, `2.`처럼 번호 목록을 사용한다.
- 하위 목록은 한 단계 내려갈 때마다 두 칸씩 들여쓴다. 번호 목록의 하위 목록은 번호 뒤 글자 위치에 맞춰 세 칸 들여쓴다.

## 7. 강조와 코드

- 강조는 `**굵게**`로 표시한다.
- 파일 경로, 명령, 설정 키, 코드 식별자는 인라인 코드(``` `...` ```)로 감싼다.
- 다른 노트를 가리킬 때는 ``[`노트 파일 이름`](노트 상대 경로)`` 형식의 링크로 쓴다. 다른 폴더의 노트도 링크 텍스트에는 파일 이름만 쓰고, 폴더 경로는 링크 주소에만 쓴다. 예: ``[`02-agent-loop.md`](./02-agent-loop.md)``, ``[`01-coding-agent.md`](../02-coding-agent/01-coding-agent.md)``
- 같은 노트 안의 장과 절을 가리킬 때는 `N절`, `N.N절`로 쓴다.
- 코드 블록은 여는 펜스에 언어를 명시한다. 디렉터리 트리나 일반 텍스트는 `text`로 명시한다.

## 8. 수식

- 수식은 LaTeX 문법으로 작성한다.
- 본문 안의 수식은 `$...$`로 감싼다.
- 독립 수식은 여는 `$$`와 닫는 `$$`를 각각 별도 줄에 놓는다.
- 수식 유도에서 근거, 가정, 치환 관계에는 `\because`를 사용한다.
- 결론 수식에는 `\therefore`를 사용한다.
- 여러 단계의 유도는 `aligned`를 사용한다. `&`로 등호 등의 위치를 맞추고 `\\`로 줄을 나눈다.
- 행렬은 `bmatrix`, 벡터는 `\mathbf`를 사용한다.

## 9. 이미지

- 노트에 이미지를 삽입하거나 수정할 때 아래 형식을 그대로 따른다.

```markdown
<div align="center">
  <img src="./figures/fNN-{name}.svg" width=80%>
</div><br>

> Figure N. {caption}
```

## 10. 표

- 노트에 표를 삽입하거나 수정할 때 아래 형식을 그대로 따른다.
- `<div>` 안에서 표 위아래의 빈 줄은 표 렌더링에 필요하므로 지우지 않는다.

```markdown
<div align="center">

| 열 제목 1 | 열 제목 2 |
| :---: | :--- |
| 내용 1 | 내용 2 |

</div>

> Table N. {caption}
```

## 11. 참고 문서

- 외부 문서에서 정의, 설명, 주장을 가져오면 본문에 인용을 붙이고, 노트 마지막에 `## 참고 문서` 장을 둔다.
- 참고 문서는 번호 목록으로 쓴다. 각 항목 앞에 `<a id="ref-N"></a>` 앵커를 둔다.
- 링크 텍스트는 `문서 이름: 가져온 내용` 형식으로 쓴다. 같은 문서에 언어별 판이 있으면 문서 이름 뒤에 `(국문)`, `(영문)`을 붙인다.
- 링크는 가져온 문장을 하이라이트하는 텍스트 프래그먼트(`#:~:text=시작 문구,끝 문구`) 링크로 쓴다.
  - 시작 문구와 끝 문구는 단어 단위로 끊는다. 한국어는 조사가 붙은 어절을 통째로 쓴다.
  - 시작 문구는 문서 안에서 한 번만 나오는 문구로 고른다.
  - 공백(`%20`), 쉼표(`%2C`), 하이픈(`%2D`), 괄호(`%28`, `%29`)는 퍼센트 인코딩하고, 한글은 인코딩하지 않고 그대로 쓴다.
  - 리다이렉트되는 주소는 최종 주소를 쓴다.
- 링크 주소는 참조형 링크로 목록 밖에 둔다. 목록 항목에는 `[링크 텍스트][rN]`만 쓰고, 목록 아래에 빈 줄을 하나 둔 뒤 `[rN]: 주소`를 모아 쓴다.
- 같은 문서라도 하이라이트 범위가 다르면 번호를 따로 매긴다. 같은 범위를 다시 인용하면 같은 번호를 쓴다.
- 번호는 본문에서 처음 인용한 순서대로 매긴다.
- 본문에서는 인용한 문장의 마침표 앞에 `[[N]](#ref-N)`을 붙인다.

```markdown
LLM 하나는 텍스트로만 응답한다[[1]](#ref-1).

## 참고 문서

1. <a id="ref-1"></a>[문서 이름 (국문): 가져온 내용][r1]

[r1]: https://example.com/page#:~:text=start%20phrase,end%20phrase
```
