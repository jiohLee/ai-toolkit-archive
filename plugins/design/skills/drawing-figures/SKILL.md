# 작업 자료

아래 파일의 원문이 context에 없으면 먼저 읽는다. 요약만 있으면 없는 것으로 본다.

- `${CLAUDE_SKILL_DIR}/references/figure-style.md`

# 입력
- 생성: figure 설명(데이터, 표기, 수식, 참고 이미지), 파일 이름, 저장 디렉터리.
- 수정: 대상 SVG와 수정 내용.
- 누락된 값은 기본 규칙을 적용

# 절차
1. 규칙에 따라 SVG를 생성 또는 수정.
2. sharp 렌더러로 생성된 SVG를 PNG로 변환.
   - 쓸 수 있는 sharp가 이미 있으면 그것을 쓴다.
   - 없다면 `${CLAUDE_PLUGIN_DATA}`에 sharp를 설치하고, 설치한 sharp를 쓴다.
3. 변환된 PNG를 시각적으로 검증.
4. 문제 발견시 수정하고 다시 검증.

## 파일 규칙
- 기본 저장 경로: 프로젝트의 `<사용자 입력>/figures/`. 없을 경우 `<프로젝트 루트>/figures/` 생성.
- 신규 파일명: `fNN-<name>.svg`.
- NN은 기존 최대 번호 + 1, 없으면 00.
- 수정 시 파일명과 번호 유지.
- PNG는 SVG와 동일한 기본 파일명 사용.

## SVG 규칙
- width: 2000px.
- height: 그림의 종횡비에 맞춤.
- 적절한 viewBox 설정.
- 편집 가능한 SVG 요소 사용.
- 데이터, 수식, 단위의 의미 보존.
- 그림 내부에 불필요한 제목, 설명 및 수식 전개 금지.
- SVG 파일 내 alt text 또는 desc 작성 금지.

## 스타일 규칙

- 색, 글꼴, 같은 스타일은 작업 자료(`${CLAUDE_SKILL_DIR}/references/figure-style.md`)를 따른다.
- 요소끼리 간섭하지 않도록 충분한 간격을 둔다.
- 요소와 표기가 멀어지면 둘 사이를 회색 실선으로 잇는다.
- 필요하면 스케일 바, 범례, 좌표축을 표시한다.

## 검증 항목
- 글자 잘림.
- 도형 또는 글자 간 겹침.
- 라벨 누락.
- 요청과 일치.
